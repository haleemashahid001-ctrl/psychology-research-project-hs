
# Study Habits and Student Well-being

## Project title
Study Habits and Student Well-being

## Purpose
This is a fictional class project for our psychology course. The purpose is to organize our team research on how study habits affect student well-being without using real participant data.

## Files
- project_plan.docx - contains our team timeline and tasks
- survey_draft.docx - draft version of the fictional survey questions
- data_dictionary.xlsx - explains the meaning of each variable in our mock dataset

## Team rules
1. Always use clear file names with dates, like survey_draft_v1.docx
2. Write a clear commit message every time we change a file so the team knows what changed
